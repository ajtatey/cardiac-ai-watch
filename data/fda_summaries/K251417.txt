Device Description [807.92(a)(4)] 
Device characteristics 
ReVISION 2 is a standalone Software as a Medical Device (SaMD) operating as a web-based 
Software as a Service (SaaS) platform. It is not part of a hardware medical device and operates 
independently as cloud-based diagnostic support software. 
 
Environment of use 
Healthcare facility/Hospital: ReVISION 2 is intended for use by healthcare professionals 
qualiﬁed to review, quantify, and report right ventricular (RV) structure and function from 3D 
echocardiographic data, to support the diagnosis of patients with suspected heart disease. 
 
General description 
ReVISION 2 is a software as a medical device (SaMD) designed to assess global and segmental 
morphology and function of the right ventricle (RV) using 3D echocardiography-derived digital 
medical data. The device accepts DICOM ﬁles acquired directly from compatible ultrasound 
systems (GE, Philips) and maintains backward compatibility with UCD ﬁles from TomTec systems. 
An AI-powered auto-contouring module automatically generates a 3D surface model of the RV 
from the input data; the user may review, edit, accept, or reject the generated contours and 
anatomical landmarks. From the resulting surface model, ReVISION 2 calculates RV volumes 
(EDV, ESV, SV), ejection fraction (longitudinal, radial, anteroposterior), global and segmental 3D 
strain (longitudinal, circumferential, area), and global, regional, and segmental curvature 
metrics characterizing RV shape remodeling. Results are presented in a structured report with 
comparison to normal reference ranges. 
The device is intended to provide information for use by the care professional, in conjunction 
with other clinically relevant information, to assist in the diagnosis of patients (adults only) with 
suspected heart disease. 
The ReVISION 2 System consists of the following components: 
 
● Web Portal: UI enabling healthcare professionals to upload DICOM/UCD studies and 
review, edit, accept, or reject auto-generated contours 
● API: interfaces between the Analytics Engine and the Web Portal 
● Analytics Engine: core computational module producing volumetric, strain, and 
curvature outputs from the surface model 
● AI Contouring Module: PyTorch-based neural network generating the 3D RV surface 
model

Substantial Equivalence (SE) discussion 
Subject Device analyzes the same inputs as the predicate devices but in a more detailed manner and provides novel measures 
without altering the raw information contained by these inputs (i.e., 3D echocardiographic videos or 3D models). Thus, these novel 
features do not raise different questions of safety and effectiveness but support clinical decision making with extra informa tion 
derived from the raw data. 
Key software features and comparisons: 
 
● Independent operation & Direct DICOM processing: Unlike ReVISION 1.0, which required a TomTec 4D RV module to 
generate the input 3D surface model, ReVISION 2 accepts DICOM ﬁles directly from GE and Philips ultrasound systems and 
generates the 3D RV surface model internally via its AI-powered auto-contouring module, while retaining backward 
compatibility with UCD ﬁles from TomTec systems. This automated contour-generation capability is functionally identical to 
the auto-contouring already present in the primary predicate (TomTec-Arena TTA2), as reﬂected in the Technical Comparison 
table above — it is new relative to the secondary predicate (ReVISION 1.0) but not relative to the primary predicate. 
● Curvature Analysis: ReVISION 2 introduces global, regional, and segmental curvature metrics characterizing RV shape 
remodeling, calculated directly from the same 3D surface model already used for volumetric and strain measurements. This is 
a novel derived measure not present in either predicate device, but it does not alter or introduce new raw input data — it is 
computed entirely from the existing, validated surface model — and therefore does not raise different questions of safety or 
effectiveness. 
● Scope: ReVISION 2's functional scope remains a subset of the primary predicate's broader intended use (RV structures and 
function only, vs. TomTec's coverage of cardiovascular, fetal, and abdominal structures across multiple modalities) — a 
narrower scope than the predicate, which supports rather than complicates the substantial equivalence argument.

Performance Data [807.92(b)] 
Performance testing supporting substantial equivalence included nonclinical testing - software 
veriﬁcation, analytical validation (auto-contouring/volumetric quantiﬁcation and curvature), 
and cybersecurity assessment - summarized below. 
 
Nonclinical Testing Summary [807.92(b)(1)] 
Software veriﬁcation 
Software veriﬁcation was performed at the unit, integration, and system levels in accordance 
with IEC 62304:2006 and the FDA's General Principles of Software Validation. Unit-level testing 
covered individual modules (auto-contouring, curvature calculation, ECG/keyframe detection, 
DICOM reconstruction) using black-box and white-box strategies; frontend and integration tests 
covered the full web application (Galactus authentication, ReVISION workﬂow) end-to-end. 
System-level testing assessed availability and recovery behavior. Detailed test plans, cases, and 
results are provided in the Veriﬁcation and Validation Report (REV2-VVR). 
Analytical validation - Auto-contouring and volumetric quantiﬁcation 
The accuracy of ReVISION 2's automated right ventricular quantiﬁcation was evaluated using 
an independent external validation dataset of 46 subjects spanning a broad range of RV sizes 
and systolic function. Automated measurements were compared against a reference standard 
generated from averaged manual contours of three expert cardiologists. Auto-contoured RVEF 
values demonstrated an absolute error tolerance of 5% on average. Performance was further 
evaluated across demographic and clinical subgroups (four deﬁned clinical study groups 
spanning heart failure, arrhythmia/hemodynamic symptoms, ischemic/valvular/structural 
disease, and cerebrovascular/systemic conditions): mean absolute errors ranged approximately 
11–21 mL for EDV, 9–12 mL for ESV, and 3–8 percentage points for RVEF, depending on 
subgroup. Observed variability was comparable to published inter-observer variability of 
manual RV contouring. 
Analytical validation - Curvature 
Curvature values calculated by ReVISION 2 were validated against Materialise 3-matic Medical 
18.0 (K060950), an FDA-cleared reference method, using the RVENet population. Global, free 
wall, and septal curvature values demonstrated moderate-to-strong correlation with the 
reference device (r = 0.6327–0.8046, all p < 0.05), meeting pre-speciﬁed acceptance criteria. 
Systematic differences between the two methods were attributable to underlying algorithmic 
differences (vertex-based vs. face-based curvature estimation) and were concentrated in planar 
valve-annulus regions, which are geometric artifacts of mesh generation rather than true 
myocardial structures and carry no diagnostic signiﬁcance. Clinically meaningful curvature - 
pertaining to the right ventricular free wall and interventricular septum, which are directly 
involved in remodeling and contractile function - showed strong agreement with the reference 
method. 
Cybersecurity 
Security assessment activities were performed in accordance with FDA's "Cybersecurity in 
Medical Devices: Quality System Considerations and Content of Premarket Submissions" 
(September 2023). ReVISION 2 is classiﬁed as Moderate Level of Concern. Threat modeling 
was conducted using the STRIDE methodology across all system trust boundaries 
(authentication, web service, database, processing modules, ﬁle storage, network 
infrastructure). DICOM input handling implements two-layer defense-in-depth validation.
