5. Device Description 
 
3D-RD-S is a  cloud-based Software as a Medical Device (SaMD) intended to estimate radiation 
absorbed dose and related quantities following administration of a radioactive product.  The software 
performs internal dosimetry calculations using established Medical Internal Radiation Dose (MIRD) 
methodology and S-value-based approaches.  The dosimetry engine, calculations, intended use, and 
outputs remain unchanged from the previously cleared 3D-RD-S device (K212587). 
 
The subject device includes an optional imaging-based functionality, referred to as 3D -RD-Si, which 
enables users to derive quantitative dosimetry input information from nuclear medicine (NM) and 
computed tomography (CT) imaging datasets.  Imaging functionality includes imag e import, image 
display, registration support, segmentation tools, and quantitative image analysis.  The system may 
provide an initial segmentation to assist the user in defining volumes of interest (VOI s); however, all 
segmentations are reviewed by the user, modified as needed, and must be explicitly confirmed prior 
to use within the dosimetry workflow.   
 
The optional imaging functionality provides an alternative method for generating quantitative 
dosimetry input information used within the established 3D -RD-S workflow. The functionality does 
not modify the dosimetry calculations, methodology, intended use, or outputs of the previously 
cleared device. All absorbed dose calculations continue to be performed using the established 
3D-RD-S dosimetry engine. 
6. Indications for Use 
 
3D-RD-S is intended to estimate radiation absorbed dose (and related quantities) to tissues after 
administration of a radioactive product.  For use with internally administered radioactive products, 
3D-RD-S should not be used to deviate from product dosing and administration instructions.  Refer to 
the product’s prescribing information for instructions.

8. Performance Testing 
 
Software Verification and Validation 
Software verification and validation activities were conducted in accordance with established design 
control procedures and a risk -based software development process.  Testing included unit testing, 
integration testing, system testing, workflow validation,  and regression testing.   All testing met 
predefined acceptance criteria. 
Non-Clinical Performance Testing 
Benchmark testing was conducted to evaluate whether imaging-derived input functionality within 3D-
RD-Si produces dosimetric outputs consistent with those generated using the previously cleared 3D -
RD-S workflow.  Testing used aligned NM and CT imaging datas ets, predefined segmentation inputs,

and analyst-directed workflows while holding segmentation inputs constant to isolate the effect of

Testing evaluated: 
• Activity quantification 
• Time-activity curve (TAC) generation

All evaluated comparisons met the predefined acceptance criterion of less than 10% difference.  
Observed average differences across evaluated datasets were below 5%, with the maximum observed 
difference being 6.74%, which remained within acceptance criteri a.  Results demonstrated that 
outputs generated using imaging -derived inputs were consistent with outputs generated using the 
established 3D-RD-S workflow. 
Clinical Testing 
Clinical testing was not required to support substantial equivalence. 
9. Conclusion 
3D-RD-S with the optional imaging-based functionality (3D -RD-Si) and Hermes Voxel Dosimetry 
(K243919) are software-only medical devices that support absorbed dose estimation through the use 
of imaging-derived quantitative information and dosimetry calculations.  Both devices utilize image 
processing, segmentation, quantitative image analysis, and user -reviewed workflows to support the 
generation of information used in absorbed dose estimation. 
 
The option al 3D-RD-Si functionality provides an alternative method for deriving quantitative 
dosimetry input information from NM and CT imaging datasets while maintaining the previously 
cleared 3D -RD-S dosimetry methodology, calculations, intended use, and outputs.  V erification, 
validation, and benchmark testing demonstrated that the device performs as intended and that 
imaging-derived inputs produce results consistent with the previously cleared workflow.  Therefore, 
3D-RD-S with the optional 3 D-RD-Si functionality is substantially equivalent to Hermes Voxel 
Dosimetry (K243919) and does not raise new or different questions of safety or effectiveness.
